## How to Run the Program

### 1. Compilation
Compile both `Q5_Client.c` and `Q5_Server.c` using `gcc`:

```bash
gcc Q5_Client.c -o client
gcc Q5_Server.c -o server
```

### 2. Execution
First start the server, then open a new terminal to run the client:

**Terminal 1 (Server):**
```bash
./server
```

**Terminal 2 (Client):**
```bash
./client
```
